# 나스닥 전략 연구 MVP

## 목적과 합의

비개발자가 서비스 안에서 매매 규칙을 바꾸고 과거 데이터로 시뮬레이션하여 원금 대비 수익과 손실 위험을 확인한다. 특정 매매법을 사용자에게 사전 제출받지 않는다. 사용자는 추가 전략 질문 대신 구현 진행을 요청했다. 기존 FastAPI·Next.js·Decimal 엔진을 유지한다.

## 범위와 구현 결정

- 개발환경과 CI를 먼저 검증한다. Python 3.12, Node 24, pnpm 11.1.2, frozen lockfile을 기준으로 한다.
- 나스닥 대표 종목을 선택하고 Yahoo의 실제 과거 데이터 또는 사용자가 업로드한 CSV/Parquet snapshot으로 실행한다. 네트워크 없는 데모는 합성 데이터임을 명확하게 표시하며 실제 시세로 가장하지 않는다.
- 한국어 폼으로 매수·매도 조건, 지표 기간, 비교 연산, 투자 비중, 손절·익절·보유 bar 수를 편집한다. 템플릿은 시작점일 뿐 고정 전략이 아니다. JSON DSL도 유지한다.
- 초기 원금, 최종 평가금액, 순손익, 비용 반영 수익률, 최대 낙폭, 거래 건수, 비용 및 자산 추이와 주문·체결 근거를 제공한다. 미청산 포지션은 평가손익이며 청산 수익으로 부르지 않는다.
- 같은 종목 단순보유를 비교 기준으로 명시한다. QQQ를 읽지 않은 실행을 QQQ 비교로 표시하지 않는다.
- 일봉과 분봉(1분·5분) 연구를 지원한다. 분봉은 bar 종료 후 신호, 다음 bar 시가 체결이다. 제공자 제한과 업로드의 timestamp 기준을 명시한다. 일봉 데이터를 분봉으로 재표시하지 않는다.
- 초단타는 bar 기반 근사 연구로 한정한다. 호가·스프레드·실제 지연·체결 대기열·부분 체결 검증은 지원하지 않는다고 상단 경고한다. 비용 조건을 바꿔 재실행하여 민감도를 확인할 수 있다. 수익 보장·실주문은 제외한다.
- MVP 실행은 bounded 동기 API이며 snapshot과 실행 결과를 immutable filesystem artifact로 보존한다. 대규모 비동기 작업 큐는 이번 MVP의 완료 조건이 아니다. 사용자 인증이 없는 로컬 연구용이며 공개 운영 배포를 가장하지 않는다.

## 정확성과 안전

미래 참조 금지, 같은 bar 종가 신호·체결 금지, Decimal 계산, snapshot checksum 검증, adjustment/timeframe/universe 불일치 거부, 업로드·expression·bar 수 제한, provider silent fallback 금지. 결과는 snapshot·전략 hash·config·engine/code revision에 연결한다. 가격 보정은 과거 시점 가용 정보가 아닐 수 있음을 경고한다. 미국 정규장/서머타임과 일봉·분봉 시간 의미를 구분한다.

## UI와 검증

결론과 제한 → 핵심 수치 → 자산 그래프 → 접힌 상세 근거. 실행 전에는 빈 상태와 바로 시작할 수 있는 폼, 실행 중에는 중복 제출 차단, 실패에는 입력을 보존한 한국어 오류를 제공한다. 390px와 1440px에서 실제 브라우저 검증, 표 내부 가로 스크롤, 키보드 조작, 그래프 최소 표시 글자 14px를 확인한다. 완료를 테스트 결과 없이 주장하지 않는다.

CI는 lint/type/unit/build, 실제 PostgreSQL migration, offline 브라우저 E2E, Compose 실행 및 이미지 빌드 검증을 담당한다. CD는 배포 대상·credential이 없으므로 승인 기반 컨테이너 발행 경로와 운영 한계를 문서화하고 자동 실서비스 배포는 만들지 않는다.
