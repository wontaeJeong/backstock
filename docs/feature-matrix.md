# 기능 우선 구현 범위

이 목록은 전략 연구와 가상매매 기능의 완료 기준이다. 운영 고도화보다 실제로 사용할 수 있는
기능을 우선하며, 계산 정확성·미래 참조 방지·승인·명시적인 데이터 한계는 생략하지 않는다.
구현 완료 표시는 API뿐 아니라 웹에서 실제 사용하고 fixture 테스트로 확인한 뒤 갱신한다.

| 기능 묶음 | 현재 기준선 | 이번 추가 범위 | 완료 증거 |
| --- | --- | --- | --- |
| 전략 작성·저장 | 한국어 단일 전략 편집/JSON 확인 | 버전 보관함, 검색/복제/불러오기, JSON 편집·import/export | 구현 후 기재 |
| 데이터 관리 | 단건 업로드/일봉 수집 | snapshot 검색·상세·재사용·보관/복원, 제한 명시 원격 분봉, tick/quote 파일 | 구현 후 기재 |
| 실행 관리 | 실행 ID 재조회·최근 5건 메모리 비교 | 서버 실행 기록 검색/페이지/보관·복원, 저장 실행 선택 비교 | 구현 후 기재 |
| 수익·위험 분석 | 원금 대비 수익·순손익·최대 낙폭 | CAGR/변동성/Sharpe/Sortino·승률·profit factor·expectancy·노출·보유 기간 | 구현 후 기재 |
| 결과 탐색 | equity/체결/주문/JSON | 낙폭·월별 수익·완료 거래, bar 상태 리플레이, 전체 CSV | 구현 후 기재 |
| benchmark | 같은 종목 비용 없는 가격 비율 | 별도 QQQ 데이터와 공통 시각 비교 | 구현 후 기재 |
| 조건값 탐색 | 한 번에 한 설정 재실행 | 지표/조건/비중/리스크/비용의 bounded grid, 실패·미실행 명시 | 구현 후 기재 |
| 시간순 검증 | 없음 | train에서만 설정 선택, 다음 test 구간의 독립 자본/주문, 여러 fold | 구현 후 기재 |
| 다중 종목 | 단일 종목 | 2~5개 독립 예산 분할 포트폴리오·잔여 현금·공통 시각 평가/상관 | 구현 후 기재 |
| 단기매매 가정 | 일봉/분봉 next-open, 수수료/slippage | spread·quote·latency·선택적 거래량 한도·stop/stop-limit·시간 조건 | 구현 후 기재 |
| 지표 | SMA/EMA/RSI/ATR/돌파·거래량/수익률 | rolling VWAP·Bollinger·MACD, 명시적 lookback | 구현 후 기재 |
| 가상매매 | 미구현 | paper 계좌·주문 제안/승인/거절/취소·잔고/포지션/감사·kill switch/idempotency | 구현 후 기재 |

## 이번에 완성했다고 주장하지 않을 항목

- 실제 broker의 모의투자/실전 계좌 연결, 실제 credential, 자동 실주문.
- 유료 실시간 tick feed 계약, 거래소 호가 queue·실제 지연/시장 충격/부분 체결 재현.
- 완전한 point-in-time 상장 universe와 corporate-action 현금/주식 원장, 완전한 거래소 calendar.
- 공유 현금·동적 리밸런싱 다중 전략 engine(이번 포트폴리오는 명시적인 고정 예산 분할).
- 다중 사용자 인증·공개 운영 보안·분산 worker/queue·Kubernetes·운영 백업.

위 항목은 빈 구현으로 완료 처리하지 않는다. 연구 결과를 실전 초단타 유효성이나 미래 수익 보장으로
표시하지 않으며, 현재 데이터/체결 모델에서 확인한 결과와 미검증 가정을 구분한다.
